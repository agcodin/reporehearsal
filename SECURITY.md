# Security policy

## Supported version

Security updates are applied to the current production deployment at
<https://reporehearsal.com> and the latest commit on the `main` branch.

## Report a vulnerability

Please report suspected vulnerabilities privately through
[GitHub private vulnerability reporting](https://github.com/agcodin/reporehearsal/security/advisories/new).
Do not open a public issue with exploit details, credentials, personal data, or
repository contents.

Include the affected URL or component, reproduction steps, impact, and any
supporting request or response details with secrets removed. You should receive
an acknowledgment within five business days. Remediation timing depends on
severity and reproducibility.

## Responsible testing

Use test accounts and repositories you control. Avoid accessing other users'
data, degrading the service, sending unsolicited traffic, or testing in a way
that could destroy or alter data. Stop and report immediately if you encounter
credentials or personal information.
