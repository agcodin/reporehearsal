# Codex usage

Codex accelerated project architecture, frontend implementation, Prisma schema design, billing fixture creation, Docker configuration, deterministic incident templates, test generation, debugging, security review, and final documentation.

Human-directed product decisions were preserved throughout:

- deterministic approved templates instead of arbitrary generated faults;
- TypeScript and PostgreSQL as the narrow MVP stack;
- hidden tests outside the exercise workspace;
- server-side command allowlists rather than browser restrictions;
- a no-API deterministic fallback;
- rejection of fixes that suppress errors, remove constraints, or disable tests;
- a local adapter behind the sandbox interface when Docker/PostgreSQL were unavailable.

GPT-5.6 is reserved for architecture explanations, adaptive hint wording, reasoning-quality review, prevention suggestions, and report prose. Zod validates structured model output, repository text is marked untrusted, and deterministic validators remain authoritative.
