# Three-minute demo script

## 0:00–0:20 — Problem

“Developers often practice incident response for the first time during a real outage. RepoRehearsal turns a codebase into a safe debugging simulation.” Show the landing page.

## 0:20–0:45 — Repository analysis

Open the billing demo and show TypeScript, Express, PostgreSQL, Prisma, routes, migrations, and detected risks. Explain that deterministic mapping precedes incident selection.

## 0:45–1:05 — Incident generation

Choose Required field migration, Intermediate, Guided. Show the clean baseline, isolated copy, injection, and symptom verification.

## 1:05–2:05 — Investigation and repair

Reproduce the request, inspect the correlated log, compare billing records, note the partner-import difference, record a hypothesis, draft the safe repair, and run public tests.

## 2:05–2:30 — Validation

Submit. Show public tests, hidden migration and account-creation checks, unsafe-patch scan, health, and unaffected behavior.

## 2:30–2:50 — Report

Show the 95-point breakdown, root cause, missed evidence, prevention suggestions, and Markdown export.

## 2:50–3:00 — Closing

“RepoRehearsal does not solve the incident for you. It gives you a safe place to learn how to solve it before production is at risk.” Mention Codex and optional GPT-5.6 enhancement.
